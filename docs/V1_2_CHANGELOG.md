# V1.2 变更记录

本轮为Stage 1.1规则工作，不包含真实行情、Web UI、自动选股或回测。原V1.1 Word保持不变；Stage 1代码、配置、182项测试和旧审计文件保存在`docs/archive/stage1_v1_1_baseline.zip`。

## 已确认语义变化

- 连续评分档统一[a,b)，结构条件明确的不等号保持原意。A3的0/3%、C2的0/0.5%/2%、D3的1.10、D4和D5端点按新规则更新。
- 所有7种确定状态都进入Coverage；F1有效上限10、F类15及其他类别封顶。风险分母为本次执行集合，前置明确不成立也属于已判断。
- C5至少5日、每个收盘>=M60、至少80%日距M60在0~8%；不再把洗盘回收计为完整平台。快速收复归C4；C4过期未确认返回FAIL。
- C6/R8分别处理完整D/W/M周期，严格收盘波谷、左右各2根确认；Low不参与破位，多个周期只取最高扣分。
- E1按日收益定义小阳/大阳，1根小阴或十字星例外；E2取最近已结束高点±2周最大周量，不要求环比增长；E3日线按80%日绝对收益<=5%、至少3涨3跌与上涨均量更大判断，不要求逐级缩幅。
- N板多起点从近到远找完整合法结构；盘中破M5不可恢复；过期为INVALIDATED。
- T板不要求开盘封停，只要求最终封停、最高价触停、盘中至少较涨停低2%；R12独立检查异常成交。
- 一字板沿用价格结构，前3日均量不超过前20日1.2倍、干净换手<=5%；未定分值保留PARTIAL。
- 空中加油保留低量涨停、高位2~6日较大量整理、M5不破、明确再启动；2/3~4/5~6日对应8/7/6分。
- 龙门为已确认压力线与M60的3%共同区域；保留单日巨大成交假摔及3日恢复确认。非涨停强度仍有用户决策项。
- R7使用冻结QuantScore>=80且非HIGH快照；完整3日最高价未达到+3%才触发。绝不将未来数据回写信号日。
- R4按最近P2、同P2峰差最小选择；候选开始发出DOUBLE_TOP_EXIT_RISK，INVALIDATED时撤销提醒及扣分。
- 补全离线B3及R12，以验证原T12和启动冲突；不接入板块网络或选股。

## 旧测试迁移而非删除

原182项测试场景全部保留。因用户明确改变规范，以下预期需要迁移：旧的端点UNKNOWN变为明确分档；过期C4由UNKNOWN变FAIL；Coverage从三状态、可能null变为七状态且封顶；N/R4多结构由UNKNOWN变合法选择；C5旧洗盘验收改为完整平台FAIL；已实现规则的旧NOT_IMPLEMENTED守卫改为相同输入下的真实结果。

原13个SKIP中12个现在实际执行；只有T20自动排名仍为明确排除的Stage 2，继续SKIP。没有把本轮失败项改为SKIP。未定交易语义在独立守卫测试中明确验证UNKNOWN，不冒充完整业务验收。
